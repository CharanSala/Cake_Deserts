# Exported 3D Dessert Models (`.glb`)

Run the Blender generator pipeline to populate this folder with all ten optimized `.glb` assets:

- `cupcake.glb`
- `brownie.glb`
- `cake-pops.glb`
- `cake-truffles.glb`
- `swiss-roll.glb`
- `pastry.glb`
- `mousse.glb`
- `cake-rusk.glb`
- `eclair.glb`
- `tiramisu.glb`

Command:

```bash
blender --background --python scripts/generate-models.py
```

Or on Windows PowerShell:

```powershell
.\scripts\generate-models.ps1
```
